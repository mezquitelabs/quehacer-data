# quehacer-data

Datos generados automáticamente por quehacer (https://quehacer.mx). **No edites esta rama a mano**: se reemplaza por
completo, con un solo commit, en cada publicación.

Los eventos provienen de **fuentes de terceros**. Cada evento enlaza a su página original, y los títulos, lugares e
imágenes pertenecen a sus fuentes; aquí no se reclama ningún derecho sobre ellos.

Para pedir que se retire un contenido, abre un issue en https://github.com/mezquitelabs/quehacer-web/issues indicando el
enlace del evento.
